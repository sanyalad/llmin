# Глоссарий LLMIN

**Activation state** — стадия допуска знания: candidate, shadow, canary, active, quarantined.

**Applicability contract** — условия совместимости и явные исключения для применения знания.

**Attempt** — одна durable попытка выполнить задачу с общей цепочкой идентичности.

**Capability** — минимальное типизированное действие, которое policy может разрешить Executor.

**ContradictionRecord** — неизменяемая запись о конфликте знаний или доказательств и его статусе.

**Cost entry** — измерение расхода по категории, единице и источнику.

**Episode** — один сохранённый случай выполнения задачи.

**Evidence** — проверяемое наблюдение, поддерживающее результат.

**Executor** — компонент, выполняющий авторизованный структурированный план.

**Knowledge Router** — компонент, выбирающий совместимый memory artifact либо fallback.

**MemoryArtifact** — управляемый объект знания с provenance, applicability и lifecycle.

**Orchestrator** — компонент, управляющий состояниями и границами одной попытки.

**Planner** — заменяемый компонент, создающий `ExecutionPlan`; LLM является одним из вариантов.

**Postcondition** — машинно проверяемое условие результата задачи.

**Provenance** — связь знания с исходными событиями, доказательствами и родительскими artifacts.

**Rule** — обобщённое знание, ещё не обязательно исполняемое.

**Shadow mode** — оценка кандидата параллельно основному пути без влияния на результат.

**Skill** — исполняемый проверенный навык с ограниченной областью применимости и fallback.

**Trace** — полный упорядоченный журнал событий попытки.

**Verifier** — независимый компонент, проверяющий postconditions по фактическому after state.
